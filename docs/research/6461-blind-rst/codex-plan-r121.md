## Verbatim review

PLAN NO

1. BLOCKER — The `!recycle_now` postblock is not final admission for the fallback arm. It only appends a request to `scratch_forwards`; actual dispatch occurs later and can still drop for a missing binding, frame-build failure, or redirect-inbox overflow. The latter even returns `Ok` after silently discarding. Thus an unforwarded packet can still advance the anchor or clear probation, contradicting the document’s commit invariant. The authority action must travel with the pending request to real dispatch/admission success. Code trace: `userspace-dp/src/afxdp/poll_descriptor/flow_cache_hit.rs:507-552` → `userspace-dp/src/afxdp/worker/lifecycle.rs:226-281` → `userspace-dp/src/afxdp/tx/dispatch/mod.rs:512-573,1378-1397`; silent overflow at `userspace-dp/src/afxdp/umem/mod.rs:1257-1321`.

2. BLOCKER — Exact-key invalidation is insufficient for precedence changes. Installing canonical K also creates reverse-translated, reverse-wire, reverse-canonical, and forward-wire query aliases. A new local alias Q can outrank a cached shared/forward-wire result while invalidating only K leaves Q’s stale descriptor active. The rule must invalidate the complete old and new accepted-query alias families, matching the existing site-2c displaced-family model. Code trace: alias construction at `userspace-dp/src/session/mod.rs:1895-1948`; consumers at `userspace-dp/src/session/lookup.rs:62-68,222-250,253-320`; local-over-shared precedence at `userspace-dp/src/afxdp/shared_ops.rs:602-635`; helper is exact-key only at `userspace-dp/src/afxdp/flow_cache.rs:1105-1120`.

3. BLOCKER — The blanket invalidation rule has no realizable producer/carrier for most writes. Fabric-return, LocalDelivery, ForwardFlow, positional reverse, and MissingNeighborSeed installs occur outside the materialization report and return only booleans. Worker-command `UpsertSynced`/`UpsertLocal` is worse: it mutates before binding polling, while `WorkerCommandResults` carries no invalidation identities and the handler owns no caches. Specify full-family OUT results, immediate current-binding drains before the next descriptor, and a separately sized all-binding command drain before RX. Code trace: `userspace-dp/src/afxdp/poll_descriptor/mod.rs:110-131,981-1008,2449-2458,2777-2787,4787-4795`; `userspace-dp/src/afxdp/forwarding/local_delivery.rs:75-115`; `userspace-dp/src/afxdp/session_glue/mod.rs:250-270,649-658,744-810`; `userspace-dp/src/afxdp/worker/loop_body/mod.rs:682-717`.

4. BLOCKER — `(nat, is_reverse)` is not a family discriminator. An exact tuple/NAT reincarnation commonly has identical values yet a different stable ID—the ABA case the ID was introduced to distinguish—so the proposed equality branch preserves K’s ID, anchor, and sticky state onto S2. Conversely, a legitimate same-family NAT/orientation update is already supported by reindexing and would be falsely reset. The transition must carry and compare stable incarnation identity; zero must fail closed. Code trace: refused synced upsert at `userspace-dp/src/session/install.rs:310-315`, ignored by materialization at `userspace-dp/src/afxdp/session_glue/mod.rs:1092-1119`, followed by promotion at `:1235-1252` and `userspace-dp/src/afxdp/session_glue/promote.rs:99-107`; current in-place snapshot/reindex at `userspace-dp/src/session/mod.rs:1344-1463`.

The named synthesis helper covers import, prewarm, and tunnel, but reverse shared rows are also constructed directly by positional reverse install, site 2b, and reverse SharedPromote; none is normatively assigned the expected ID. There is nowhere to retain “expected but not yet verified” until promotion. Site 2c says every current FIN/RST is refused, yet `raw_flags | replica_close_bits` lets a blind RST upgrade an alive or FIN-only replica to reset/2-second state. Suppressing all close bits instead would erase a trusted stored FIN/RST. Define the state seed as stored trusted close bits plus only accepted current close bits. Specify `family_handle: Option<_>` with all forward-family authority suppressed when absent, or force these cache hits through slow resolution.
