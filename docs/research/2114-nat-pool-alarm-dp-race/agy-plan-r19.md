### (B) Fresh Attacks & Analysis

- **Attack 5(a): Pending-shaped deferred record expires during uptime** — **FAILED**
  - *Analysis*: Suppose a record is unreadable at boot (BOOT-origin terminal latch set) and becomes readable 5 minutes later. The probe clears the latch, re-seeds `onDiskArmID`, and defers record action to the next boot. If the daemon runs for 30 days without restart or operator commit, and is rebooted on day 30, boot recovery evaluates the expired branch and reverts the active config.
  - *Why it fails as a defect*: This is the intended and documented design trade-off ([plan.md:1505-1510](file:///home/ps/git/kimi-xpf/.claude/worktrees/2114-research-nat-pool-alarm-dp-race/docs/research/2114-nat-pool-alarm-dp-race/plan.md#L1505-L1510)). The journal and runbook explicitly instruct the operator to restart immediately after restoring file readability so boot recovery can re-arm/evaluate the record within its window. If the operator ignores the runbook and never confirms or commits, reverting at the next boot strictly enforces Invariant 12 / #4577 ("an unconfirmed config must never stand"), while avoiding unsafe in-process reverts/re-arms after control plane managers are already actively serving.

- **Attack 5(b): Probe re-seed clobbers a newly armed window identity** — **FAILED**
  - *Analysis*: Suppose debt-origin latch is set on $A$. An operator arms new window $B$ via `CommitConfirmed`. `writeConfirmState` creates $B$ with `ArmID_B`, setting `s.armedArmID = ArmID_B` and `s.onDiskArmID = ArmID_B`. When the probe next executes `ReadConfirm`, it reads $B$ cleanly and re-seeds `s.onDiskArmID = ArmID_B`.
  - *Why it fails*: `s.onDiskArmID` was already `ArmID_B` from `writeConfirmState`'s successful write, and `s.armedArmID` remains `ArmID_B` (the active in-memory window timer). When the debt retry for $A$ runs, it compares debt key `ArmID_A` against `confirm.json`'s `ArmID_B` (mismatch), durably verifies $B$, and clears stale debt $A$. $B$'s live in-memory window `s.armedArmID` and timer are untouched.
