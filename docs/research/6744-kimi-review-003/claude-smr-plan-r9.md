A dropped RG0 event therefore bypasses the gate. The demotion contract is also internally unimplementable as one synchronous pre-actuation call: traffic removal may proceed immediately, while later ownership duties must await drain ([plan.md:1272](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1272)). Specify a split begin/drain-completion transition, invoke it from both event and reconciliation paths, and test dropped-event promotion/demotion through production paths.

2. **Authoritative receive can start before its reconciliation authority exists.** `SessionSync.Start` exposes listeners before runtime and role callbacks are installed ([daemon_ha_sync.go:1138](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/daemon/daemon_ha_sync.go:1138), [daemon_ha_sync.go:1164](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/daemon/daemon_ha_sync.go:1164)). Current reconciliation treats nil runtime or an empty zone snapshot as a successful skip ([sync.go:1106](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/cluster/sync.go:1106)). The plan must wire runtime, role, and the current `d.applyResult()` zone map before `Start`, or add explicit initialized readiness that rejects BulkStart without ACK/callback/readiness. An initialized legitimately empty map must be distinguishable from “not wired.”

3. **Clustered full-replacement retry debt has no owner or retry consumer.** The plan says debt retains the desired generation and staged payload ([plan.md:1122](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1122)), but does not define storage, supersession, retry trigger, or how normal HA updates are suppressed while debt exists. Existing debt is standalone-only and deliberately refuses to run while clustered ([manager_ha.go:139](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/dataplane/userspace/manager_ha.go:139)). Meanwhile the status loop refreshes and republishes current `m.haGroups`, then may rearm forwarding ([process_status.go:211](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/dataplane/userspace/process_status.go:211), [process_status.go:240](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/dataplane/userspace/process_status.go:240)). After a failed staged transition this can replay the old full map. Define the clustered debt state machine, its sole consumer, generation supersession, and gating of watchdog/active/forwarding publication until the complete staged payload succeeds.

4. **Capability negotiation has wire shape but no resolved connection state.** The plan requires local capability transmission before registration ([plan.md:1387](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1387)), yet remote capability may not have been read when registration immediately triggers cold-prime. Current code installs and starts bulk directly ([sync_conn.go:130](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/cluster/sync_conn.go:130)). In keyed-to-legacy operation, authentication can also consume a first legacy data frame, which is currently dispatched before registration ([sync_conn.go:119](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/cluster/sync_conn.go:119)). Specify `unknown/capable/legacy` resolution, when a connection becomes eligible for authoritative outbound bulk, and ordering for the pending handshake frame. Tests must delay the peer capability and cover new/new, new/old, old/new, keyed, and unkeyed directions.

5. **A type-29 repair is bound to one connection but BulkSync may use another.** The receiver requires the echoed request on the same capable connection ([plan.md:1559](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1559)); the sender records that source incarnation but merely claims its tuple before selecting a still-live bulk connection ([plan.md:1568](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1568)). Pin repair bulk to the request connection, or deliberately relax the receiver invariant. Also define a deadline for `awaitingAttempt`; only write and ACK timeouts currently exist. Test a request on fabric 1 while fabric 0 remains preferred.

6. **“Bounded” receive reconciliation has no cancellation or shutdown contract.** The plan calls reconciliation bounded and blocks reconnect until it returns ([plan.md:1508](/home/ps/git/xpf-worktrees/6744-plan-r9-review/docs/research/6744-kimi-review-003/plan.md:1508)), but `ReconcileClusterBulk` accepts no context ([session_store.go:75](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/dataplane/session_store.go:75)), while `Stop` abandons its wait after five seconds ([sync_conn.go:349](/home/ps/git/xpf-worktrees/6744-plan-r9-review/pkg/cluster/sync_conn.go:349)). Specify cancellation or a joined worker lifetime that cannot outlive SessionSync/dataplane teardown. Test blocked reconciliation against disconnect, role transition, config apply, and shutdown.
