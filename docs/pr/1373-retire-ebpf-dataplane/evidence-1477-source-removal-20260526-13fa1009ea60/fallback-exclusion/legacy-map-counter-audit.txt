### Conclusion
The legacy XDP and TC C source files listed above were deleted in #1476;
bpf/headers/ remains because the retained Rust AF_XDP shim build and the
userspace-dp parity tests still consume those structs (see CLAUDE.md Code
Layout). All remaining xdp_main_prog references are retirement-boundary
sentinels (pkg/dataplane/loader.go: defaultXDPEntryProg constant used by
the retained Rust shim loader; shim_loader_boundary_test.go: canary that
asserts the shim entry stays named xdp_main_prog; manager.go: log message
referencing the historical name).
