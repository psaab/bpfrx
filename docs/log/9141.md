# #9141 — resolveDHCPRethInterfaces mutated the shared active config

## Summary

`resolveDHCPRethInterfaces` rewrote `group.Interfaces[i]` IN PLACE, and every
call site reached that slice from the daemon's shared active `*config.Config`.
Two callers did `dhcpCfg := cfg.System.DHCPServer` first — a SHALLOW struct copy
over a pointer (`DHCPLocalServer`), a map of pointers (`Groups`) and a slice
(`Interfaces`), all of which stay shared. The third
(`applyServicesReconcile`, `daemon_apply_routing.go`) passed
`&cfg.System.DHCPServer` with no copy at all.

The function now RETURNS a copy. The standalone derivation is named
`desiredStandaloneDHCPConfig`, the sibling of the existing
`desiredClusterDHCPConfig`, so both paths return a desired config instead of
editing one.
