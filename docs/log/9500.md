# 9500 — the mutation harness's "the machine broke" detector matched a string the healthy machine prints

- **Timestamp**: 2026-09-09
- **Action**: fix the infra-VOID predicate + two self-test cells + mutation proof
- **File(s)**: `scripts/mutate-lib.sh`, `scripts/mutate-selftest.sh`

## The defect

`mutation_infra_broken` was:

```sh
grep -qiE 'no space left on device|cannot allocate memory' "$1"
```

`pkg/configstore/persist_failure_test.go:22` declares

```go
var errDiskFull = errors.New("injected: no space left on device")
```

and `TestSyncApply_DegradesNotFails` deliberately returns it **while expecting
`SyncApply` to succeed**. `store.go` routes it to
`noteActivePersistFailureLocked`, which `slog.Error`s it. So the literal is
emitted by a **passing** test.

## Why it reached the cell log — the part that makes it total

`scripts/mutate.sh:55` runs its Go gate as

```sh
(cd "$REPO" && GOTESTJSON="$GOTESTJSON_LOG" timeout ... make test-go) 2>&1
```

`GOTESTJSON` selects `go test -json`, and **`-json` implies `-v`** — so a
passing test's output is streamed rather than suppressed, and `2>&1` puts it in
the very log this predicate greps. Without `GOTESTJSON` a bare `go test ./...`
hides it, which is why this was invisible in casual use and total under the
harness.

`mutation_verdict` tests infra **FIRST** (`:203-205`), so it outranks both
`KILLED` and `ESCAPED`, and `mutation_verdict_for_target` preserves every
non-`KILLED` verdict unchanged. Net effect: **every Go mutation cell** scored
`VOID(infrastructure: disk or memory)`, and **ESCAPED became unreachable** —
the verdict that says *"this code is untested"* was replaced by *"go look at
your disk"*, which is fine.

## Measured end to end, not read

```
$ go test -json -count=1 ./pkg/configstore/ -run TestSyncApply_DegradesNotFails
exit=0                                            # the test PASSED
literal hits in the -json log: 1
shipped predicate on that GREEN log: VOID(infrastructure)
```

## The fix

```sh
mutation_infra_broken() {
	grep -viE 'injected:' "$1" | grep -qiE 'no space left on device|cannot allocate memory'
}
```

Excluding the whole LINE is deliberate: a real ENOSPC arrives on its own line
as a compiler or linker diagnostic, so dropping fixture lines cannot mask one.
The memory half has no collision today (`cannot allocate memory` appears in no
fixture in this tree) but is filtered through the same pass so a future
injected-OOM fixture cannot reintroduce this.

## Acceptance — two cells, and the second is the one that matters

| Cell | Asserts |
|---|---|
| `the configstore ENOSPC FIXTURE on a green run is not infrastructure` | the defect: a `-json` log carrying only the fixture scores **ESCAPED**, not VOID |
| `a REAL full disk alongside the fixture is still VOID` | **the control**: "stop detecting ENOSPC entirely" satisfies the first cell. A real disk line in the SAME log must still be VOID, or the repair has bought a false ESCAPED — a claim that code is untested — for a run that measured the machine |

The first draft of the control asserted `yes 1 1 VOID(...)` against a
`[build failed]` fixture and RED. The predicate was right and my **expectation**
was wrong: a build-failed log scores `built=no, failed=0`. Re-cut to mirror the
existing `disk.log` fixture (a named `--- FAIL` plus a disk line) with the
injected line added, which is the shape that isolates the one variable.

## Mutation score

| Mutation | Result |
|---|---|
| remove the `injected:` exclusion (restore the defect) | **KILLED** — fixture cell reds, control stays green |

That is the two-direction result the fix needs: the mutant reds the cell that
describes the defect and leaves the control green, so the cell binds the fix
rather than the fix's shape.

## Why this was worth interrupting the campaign for

Four fix lanes are mutation-scoring right now, and this harness is the shipped
instrument. A silent conversion of ESCAPED into VOID does not just lose
information — it inverts the one signal that says a guard is missing, and it
sends the reader to inspect hardware that is healthy. Discovered by a research
run chasing the same predicate flaw I had put in four lane briefs by hand; the
briefs were corrected first, and this is the tooling half of the same mistake.
