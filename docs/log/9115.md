# #9115 — ARP/NDP learn arms accepted a group or all-zero hardware address

- **Timestamp**: 2026-09-06
  - **Action**: added `neighbor_mac_is_learnable` — the missing L2 counterpart
    to the long-standing `neighbor_ip_is_learnable` — and routed all THREE
    neighbour-learn arms through it.

    `outline_arp_reply_learn_and_program` and `outline_ndp_na_learn_and_program`
    gated on the IP alone (`neighbor_ip_is_learnable` + `!owns_configured_ip`)
    and then inserted whatever hardware address the frame carried into
    `dynamic_neighbors` AND programmed it into the kernel via
    `add_kernel_neighbor`. The sibling RX-learn arm in `neighbor_dispatch.rs`
    had always refused these, INLINE — which is the drift a shared, named
    predicate prevents, so that inline test is now a call to the same function.

    **What an attacker needs**: L2 adjacency to an interface the firewall learns
    on, and the ability to emit one ARP reply or one NDP NA. No credentials, no
    prior state, no session. The victim IP only has to be learnable and not
    firewall-owned. The result is a neighbour entry for the victim IP whose MAC
    is a group or broadcast address, in the userspace cache AND in the kernel:
    traffic for that IP is then addressed to a group and reaches every station
    on the segment, and the firewall's own switch port can be MAC-flapped or
    err-disabled. That is a cache-poisoning primitive, not merely a wrong entry.

    **A vacuous test caught mid-flight, which is the part worth reading.** The
    first NDP cells built a valid NA and then rewrote the TLLA bytes in place.
    The builder stamps the ICMPv6 checksum OVER the TLLA and the NA parser is
    strict about it, so the edited frame failed to parse and the cell passed
    because the NA was malformed — not because the guard refused it. It looked
    green and proved nothing: the mutation removing the NDP guard SURVIVED with
    those cells in place. The builder is now parameterised on the TLLA MAC so
    the checksum covers the value under test, and the cell asserts
    `parse_ndp_neighbor_advert(&frame).is_some()` as an explicit precondition so
    the same trap cannot recur silently.

    Mutants, each verified to BUILD before scoring and each restore verified by
    reading the file back: removing the ARP arm's guard reds only the ARP
    refusal cell (leaving the predicate cell green — a call-site binding, not
    just a function binding); removing the NDP arm's guard reds only the NDP
    refusal cell; making the predicate accept everything reds both refusal cells
    and the predicate cell; making it refuse everything reds both CONTROLS,
    which is what stops a "refuse all" fix from passing as a security
    improvement while breaking neighbour learning outright.

    HA wire: nothing moves. No session key and no wire struct.
