- **Timestamp**: 2026-09-07
- **Action**: Implemented glob matching rather than the minimum refusal.

  wildcard-shaped group key takes the wildcard branch in `mergeNodes` — the
  branch that merges into each matching destination and NEVER appends. The
  phantom is therefore removed by construction, independently of whether the
  pattern matches anything. `keysMatchWildcard` glob-matches the pattern.
  `*` crosses `/` (path.Match would not, and every interface name has one);
  `?` is unreachable (the lexer rejects it).
