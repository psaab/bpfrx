- **Timestamp**: 2026-09-02
  - **Action**: Added `harness-result.sh` — the adapter table mapping each
    measurement tool's verdict vocabulary onto the strings PASS/FAIL/VOID, a
    validating emitter that appends one JSON row per gate run to the tracked
    `test/results/ledger.jsonl`, and a run wrapper. The verdict is a string
    because the tree's own tools contradict each other on `exit 1`
    (`newflow_ceiling_analyze.py`: "did not measure"; `mouse_latency_aggregate.py`:
    "measured regression"; `iperf-throughput-lib.sh`: no void state at all).
    One `ha-smoke` adapter covers all 8 destructive HA smokes plus
    `test-connectivity.sh` by matching the NUMERIC TAIL rather than the label
    prefix, which varies across those nine.
  - **File(s)**: `test/incus/harness-result.sh`,
    `test/incus/harness-result-selftest.sh` (76 cells), `Makefile`,
    `scripts/run-selftests.sh`, `.gitattributes`,
    `test/results/ledger.jsonl`

- **Timestamp**: 2026-09-02
  - **Action**: Added `ledger_compare.py` — a band over the last K>=3 GREEN
    runs of one gate at one env (median +/- max(3*1.4826*MAD, 5% of |median|)),
    with VOID rows excluded from the band and from the K floor, `NO-BASELINE`
    distinct from `PASS`, and invariant metrics banded beside the headline so a
    flake candidate is distinguishable from a regression candidate without
    re-running. Plus `ledger-lint`, registered as a `make selftest` leg, which
    fails on a zero-row ledger and names the first unparseable line.
  - **File(s)**: `test/incus/ledger_compare.py`,
    `test/incus/ledger_compare_test.py` (34 cells),
    `scripts/run-selftests.sh`, `Makefile`

- **Timestamp**: 2026-09-02
  - **Action**: Added the mutation gate over the comparator and the adapter
    table — 20 cells, all KILLED, with a positive control (the unmutated copies
    must be GREEN, or the run is reported VOID rather than a clean sweep of an
