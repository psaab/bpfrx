# 8352 — a census over `#[ignore]`d Rust cells

- **Timestamp**: 2026-09-03
  - **Action**: Added `scripts/ignored-cell-census.sh` + `make
    ignored-cell-census`, registered as a `make selftest` leg. An `#[ignore]`d
    fail-until-fixed cell had no wake-up: `#[ignore]` is invisible to `make
    test-rust`, so when the defect it documents is fixed the cell stays
    ignored, stays green, and guards nothing forever — a done-signal arranged
    at a layer the completing change never reaches. The census asserts every
    `#[ignore]` carries a reason, that the reason DECLARES its kind with an
    explicit marker (`MEASUREMENT: …` or `#<issue>: …`), and — with `gh` — that
    every named issue is still OPEN, so closing it reds the census.
  - **File(s)**: `scripts/ignored-cell-census.sh`,
    `scripts/run-selftests.sh`, `Makefile`

- **Timestamp**: 2026-09-03
  - **Action**: Declared the four cells the census found undeclared: two bare
    `#[ignore]`s on micro-benchmarks in `queue_ops/tests/bench.rs`, and two
    whose reason described a measurement only in prose. The marker is required
    rather than the phrase matched: exempting on the words "measurement, not an
    assertion" would die to paraphrase — rewording a comment would silently
    convert a measurement into an unchecked cell or the reverse.
  - **File(s)**: `userspace-dp/src/afxdp/cos/queue_ops/tests/bench.rs`,
    `userspace-dp/src/io_uring_write_tests.rs`,
    `userspace-dp/src/afxdp/neighbor_dispatch_mirror_tests.rs`

- **Timestamp**: 2026-09-03
  - **Action**: Self-test with 11 cells, hermetic via a MOCKED issue-state
    command so the branch carrying the whole point (an issue CLOSES → the
    census reds and names the cell) runs without a network. Paired throughout:
    every failure fixture has a nearly-identical twin that must pass. Includes
    the empty-sweep FAIL, "could not ask" never reading as "they are open", a
    no-`gh` SKIP that still fails an undeclared cell rather than becoming a
    blanket skip, and a MUTATION of the classifier that must trip the census's
    own positive control. Fixed one defect in the self-test harness: `out=$(run_census …)`
    ran the helper in a subshell, so the rc assigned inside was discarded and
    four failure cells read rc=0 — passing while the census was working.
  - **File(s)**: `test/incus/ignored-cell-census-selftest.sh`
