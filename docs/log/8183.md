# #8183 — the two `show interfaces` surfaces disagreed about host-inbound

- **Timestamp**: 2026-09-04
- **Action**: Routed the gRPC `ShowInterfacesDetail` host-inbound render through
  `config.InterfaceHostInboundEffective`, matching the local CLI, and pinned the
  agreement so the two cannot drift again.

  Premise verified by RENDERING both surfaces over one config before changing
  anything, not by reading: for `lo.0` with a zone admitting `ssh telnet` and an
  interface stanza of `{ ping; }`, the resolver said `svc=[ping] overridden=true`,
  the local CLI printed `ping`, and the gRPC surface printed `ssh telnet`.

  **Census of every surface that makes a per-interface host-inbound claim**,
  which is the #8258 class this issue is an instance of:

  | surface | state |
  |---|---|
  | local CLI `show interfaces` (`cli_show_interfaces.go`) | correct |
  | local CLI `show interfaces detail` (`cli_show_interfaces_detail.go`) | renders no host-inbound line at all |
  | gRPC `ShowInterfacesDetail` | WRONG — fixed here |
  | remote CLI `show interfaces` (`cmd/cli`) | wrong, INHERITED — prints the gRPC Output verbatim, so fixed for free |
  | local CLI `show security zones` | correct (`HostInboundViewWithLifelines` resolves per interface) |

  Deliberately out of scope, and named rather than skipped: the zone-level
  structured fields in `pkg/api/security.go` and `pkg/grpcapi/server_show_zones.go`
  expose a ZONE's set as a zone attribute, which is not a per-interface claim.

  The cells assert AGREEMENT between the two renderers, never a literal — the
  golden files already pinned the broken side, so a literal would have encoded
  the wrong answer. Agreement alone is not enough either (two surfaces broken
  identically agree), so each case also anchors both to
  `InterfaceHostInboundEffective`, a third party rather than a literal.

  The golden `server_show_golden.json` did NOT move, contrary to the issue's
  prediction: its fixture declares no `host-inbound-traffic` stanza and its
  interfaces are not present as kernel netdevs, so no logical-interface block
  renders.

  Validation: 8 mutations, all killed, no survivors. `M8 gRPC deny line renders
  for a LIFELINE too` SURVIVED the first table — no fixture made the interface a
  lifeline — and is now bound by a chassis-cluster case that makes `lo` a
  control-interface.
