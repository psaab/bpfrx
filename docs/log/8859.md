# #8859 — brace-elision container-pair sweep instrument

- **Timestamp**: 2026-09-05
  - **Action**: committed the instrument behind the #8859 table, so the 64 rows
    can be re-derived rather than inherited. A table nobody can regenerate is a
    claim; a table with its instrument is evidence.
  - **Ratio**: 64 pairs swept — 45 candidate-drop (43 SILENT, 1 STRICT-REJECTS,
    1 WARNS), 18 SAME, 1 no-reference. NOT 45 defects: 9 verified, 35 unverified.
  - **The gate column**: every candidate is also asked whether the strict path
    refuses it or the lenient path warns. A dropped value the operator is TOLD
    about is handled, and from the compiled config alone a handled drop is
    indistinguishable from an unhandled one — which is how `system login`
    (#6662/#6706 `LoginDroppedByPacking`) sat in the candidate set looking
    exactly like a defect. It returns as STRICT-REJECTS and serves as the
    positive control.
  - **The 18 SAME are the negative control** and are kept deliberately: an
    instrument that flagged all 64 would be measuring itself.
  - **File(s)**: pkg/config/compact_elision_sweep_test.go
