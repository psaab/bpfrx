## Decline 2 — the NO-REFERENCE row, and what it actually was

The sweep's one NO-REFERENCE row, `firewall three-color-policer <name>`, reads

own assertion so the reason cannot rot into the wrong one.

## The sweep's population is contaminated — 16 pairs, 108 sites

Chasing the row above surfaced a defect in the instrument. `TestSweepFull`
skips already-admitted pairs with `compactNormalizeInScope(stanza, child)`
where `child` is `s.container[1]`. For a named-instance container that element
holds TWO tokens — `"three-color-policer xpfarg"` — while the predicate is
keyed on the bare keyword. The filter therefore never matches, and
already-admitted pairs stay in the population.

Measured: **16 distinct pairs / 108 sites**, and all 16 reach the published
table — 15 as SAME, 1 as NO-REFERENCE:

    applications application / application-set, class-of-service interfaces /
    scheduler-maps / schedulers / traffic-control-profiles, event-options
    policy, firewall policer, firewall three-color-policer, policy-options
    community / policy-statement, routing-options rib, schedulers scheduler,
    snmp community, snmp trap-group, system backup-router

This is the same keying bug the #8852 census had and fixed (an element can hold
spaces; `strings.Fields(strings.Join(container, " "))` is the fix there).

**It matters because it inflates the benign column.** Those 15 rows read SAME
*because the fold already handles them*, not because the spellings are
naturally equivalent — verified two-sided: removing the admissions for
`firewall policer` and `snmp community` makes their spellings DIFFER.
(`applications application` is admitted by another route and the control does
not apply to it, so it is excluded from that claim.)

Correcting the denominator changes the published shape of the problem:

| | as published | unadmitted only |
|---|---|---|
| pairs swept | 50 | 34 |
| SAME | 21 | 6 |
| SILENT | 26 | 26 |
| silent fraction | 52% | **76%** |

The correction makes the problem look WORSE, which is the direction that
deserves the extra scrutiny it got: the 16 were enumerated, all 16 located in
the published table, and the causal claim controlled two-sided rather than
asserted.
