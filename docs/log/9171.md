## The combination

Half one: the trust check tested `S_IWOTH` only, so a **root-owned but
group-writable** runtime directory passed. Half two: the helper's event-socket
**client** was the one leg with no peer verification.

Separately each was dismissed, and the dismissals referenced each other — the
missing peer check was read as "needs write access to a root-owned directory,
i.e. root already", and the missing group arm as "fail-closed via peercred ⇒ DoS
only". **Each assumed the other held.** Together: a member of that group unlinks
the socket, binds their own, and the helper's 100 ms reconnect loop delivers the
live session-delta stream plus `FullResync` — the session table, addresses, ports
and zone identity — and accepts forged ACKs back.

## The issue's map was wrong; the finding was not

It cites `pkg/daemon/boot_probe.go`, which **does not exist** (the file is under
`pkg/dataplane/userspace/`), and describes three separately-checked Go dials.
They in fact share **one choke point**, `dialTrustedHelperSocket` — better than
three checks, and the reason those legs were never the defective one. The table
here was built by enumerating the tree rather than transcribing the issue.

## Group exemptions, mirroring the arm above it

gid 0 and the daemon's own egid are accepted: membership of the root group is
already root-equivalent wherever this check could help, and refusing the daemon's
own group would refuse the directory the daemon creates. Sticky and
group-*readable* are unaffected — both have narrowness rows.

## Making the peer decision drivable

A refusal needs a peer running as a **different uid**, and becoming one needs a
capability the test binary lacks. So the arms were unreachable from any cell —
and a mutation making the check unreachable **survived every source-level
assertion**, because the checker's NAME was still in the file.

`peer_uid_refusal` is split from the syscall shell for exactly the reason
`runtimeDirTrustError` already is on the Go side, and that function says so:
**a test needing a kernel capability STUBS it rather than skipping**, because a
skip is indistinguishable from a pass in every summary line.

That still did not bind the *wiring*, so a third cell asserts the shape of the
defect directly: **no success path may return the stream without passing through
the check**. Narrow on purpose — it is the failure mode, not a transcription, so
an honest refactor that keeps the check still passes.
