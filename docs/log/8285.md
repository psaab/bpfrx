# #8285 — abort evidence must survive the retry

- **Timestamp**: 2026-09-02
  - **Action**: enumerated the abort path empirically before designing a
    carrier, which refuted this issue's own premise and exposed a sharper,
    reachable defect. Shipped the sticky per-box divergence record instead of
    the typed carrier the issue asked for.
  - **File(s)**: pkg/dataplane/hostdivergence_8285.go,
    pkg/dataplane/hostdivergence_8285_test.go, pkg/dataplane/loader.go,
    pkg/dataplane/armcoverage_abort_7289.go, pkg/dataplane/README.md
  - **The enumeration, because it changed the answer.** This issue (mine, filed
    hours earlier from a correct sub-finding) said abort evidence has no carrier
    that exists on the abort path. The sub-finding was right — an aborted apply
    never constructs an `ApplyResult` — and my generalisation from it was wrong.
    Traced hop by hop at `origin/master`: `annotateHostMutationOnAbort` wraps
    with `%w`, `abortAfterHostMutation` returns it unchanged,
    `CompileUserspaceShim` -> `manager_compile.go:246` -> `manager.go:496` are
    each a bare `return nil, err`, and `daemon_apply_dataplane.go:176` calls
    `recordCompileFailure(err)` BEFORE the abort-class branch, which stores
    `compileLastError` and surfaces it through `CompileHealthSnapshot` to
    `/health` — while the same error is also joined into the commit the operator
    sees. **The carrier exists and already has two live consumers.**
  - **What is actually broken.** `hostMutations` is per-COMPILE and fires only
    on a real change (`if vlanCreated`; `reconcileInterfaceAddresses` returning
    true), and `annotateHostMutationOnAbort` returns the error unchanged when
    nothing moved. Both correct alone. Together: apply #1 moves the host and
    annotates; the operator retries; the retry's Phase 2 is converged so it
    records nothing and the abort is BARE — on a box that is still diverged.
    The retry is the expected next action, and #7289's r1 established the
    reachable trigger is persistent, so the un-annotated case is the steady
    state rather than an edge case.
  - **Decision note — why not the typed/phase-aware carrier R2 asked for.**
    Adding structure to a surface nobody was missing would have been inert: the
    prose already reaches both consumers, so a new typed field would have had no
    reader and every test would still have passed — which is the tell, not the
    reassurance. The defect that survives the enumeration is evidence LOSS, not
    evidence FORMAT, and fixing it needs no new surface at all.
  - **Test note**: five cells, six mutations, each red on the right one.
    Inherit as a no-op and inherit-unwired red different cells (mechanism vs
    wiring); record-replaces-instead-of-merges reds the union cell;
    clear-as-a-no-op and clear-unwired red different cells; and
    **always-annotate — the obvious sticky-flag implementation, which passes
    the headline retry cell — reds the control**, because an annotation that
    fires on every abort stops meaning anything, which is the property the
    #4960 comment states in its own words.
