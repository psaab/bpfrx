## Severity is not uniform across these four, and the table above hides that

Two rows carry `warns=1/0` — the braced arm raises an advisory the elided arm
does not. Reading those advisories changes what the drop costs:

- `class-of-service rewrite-rules exp` → *"accepted for compatibility but
  inert: the userspace dataplane rewrites dscp on egress only, so MPLS EXP
  rewrite has no runtime effect"*
- `security pre-id-default-policy then log session-init` → *"accepted for
  compatibility but is inert in the userspace dataplane"*

So for those two the value has **no runtime effect either way**. What the
elision actually costs is the **ADVISORY**, not the behaviour: the operator
writing the elided spelling gets neither the inert config nor the notice
telling them it is inert. That is a real loss — it is how someone discovers
their MPLS EXP rewrite was never going to work — but it is not the same
severity as `classifiers` or `lldp` losing live configuration, and presenting
all four as equivalent would overstate two of them.

Recorded in the cell next to each fixture rather than only here, so the
distinction travels with the code.
