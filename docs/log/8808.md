# #8808 — CLAUDE.md's dual-AST example did not illustrate the dual AST

- **Timestamp**: 2026-09-05
  - **Action**: replaced the wrong example, corrected the issue's own phrasing
    of the claim, and landed a guard so the section cannot rot again.

    The section existed to teach that flat `set` and hierarchical braces build
    different trees, and its only example was `family inet`, for which they do
    not. Measured:

    ```
    FLAT  set interfaces eth0 unit 0 family inet dhcp
    HIER  interfaces { eth0 { unit 0 { family inet { dhcp; } } } }
      -> both: [interfaces] > [eth0] > [unit 0] > [family inet] > [dhcp]
    ```

    `family` is `compoundKey: true`, so `SetPath` consumes the sub-key into the
    same node the hierarchical parser does.

    **The issue said "byte-identical"; the correct claim is "structurally
    identical".** `reflect.DeepEqual` reports them UNEQUAL, and the reason is
    not structural — the hierarchical parser records `Line`/`Column` while
    `SetPath` leaves them zero. Measured as the ONLY difference at every node.
    That distinction is not pedantry: it decides the guard's design. A DeepEqual
    assertion here fails for a reason unrelated to AST shape, and the natural
    way to make it pass is to loosen the comparison until it no longer
    discriminates at all — so the cell compares structure explicitly and proves
    separately that position metadata is the only thing it ignores.

    The replacement example is `protocols bgp group g1 neighbor <ip> peer-as
    <as>`, where flat builds a CHAIN and the hierarchical spelling builds
    SIBLINGS.

    **I committed this issue's own defect once while fixing it.** My first
    replacement wrote the hierarchical form as nested braces
    (`neighbor 10.0.0.1 { peer-as 65001; }`), which is a chain in both
    spellings — an example illustrating nothing, exactly like the one being
    removed. My own guard caught it, which is the argument for writing the
    divergence assertion rather than only the two shape assertions.

    Mutation: making `family` non-compound in `ast_edit.go` reds the converge
    cell; rewriting the replacement example back into nested braces reds the
    divergence cell with "this example teaches nothing".
