# 8880 — the fold stranded what it did not consume

**Action**: `compact_normalize_8662.go` declines a fold that would strand a
continuation; two cells in `fold_strands_remainder_8880_test.go`.

## The defect

`security { policies from-zone a to-zone b {…} from-zone c to-zone d {…} }`
compiled to ONE zone pair where the braced spelling gives two — clean commit,
zero warnings, on the primary enforcement surface.

## The mechanism is stranding, not a failure to split

The parser splits a run packed onto an elided container's line into SIBLINGS,
and only the first carries the container keyword:

    [policies from-zone a to-zone b]{…}   -> folds into `policies`
    [from-zone c to-zone d]{…}            -> left behind

The fold built `policies { from-zone a … }` and left the second block as a
sibling — a `from-zone` node directly under `security`, a position the schema
does not model, which the compiler ignores without a word.

## `packedStatements` is not the fix — measured

Setting `packedStatements: true` on `policies` left the packed arm at one zone
pair. That flag splits a packed TAIL; this is a sequence of BRACED BODIES after
an elided container brace. Different code path. The proposed remedy in the issue
body was wrong and testing it before claiming the issue is what caught that.

## Why decline rather than absorb

Absorbing the continuation means rewriting the PARENT's child slice;
`normalizeCompactNodes` receives a slice and the parent schema, not the parent
node, so it cannot. Declining is the established response (#8866).

The check is "the next sibling's head is a declared child of the container", not
"it is unambiguous". Measured: 348 of 384 (parent, container) pairs share no
child name, but 36 do — `class-of-service > interfaces` shares `classifiers`
with its own parent — and there a continuation cannot be told from a sibling.
Declining covers both.

## Blast radius, measured

62 folds across the shipped `.conf` corpus with the fix; 62 without. The decline
suppresses none of them.

## What this closes and what it does not

Closes the STRANDING: the fold no longer produces a tree the compiler cannot
represent. Does NOT make the packed spelling work, and does not make it loud —
an unknown child of `security` still commits clean, tracked separately as the
closed-world coverage gap. After this the packed form applies NOTHING rather
than half, which is the honest outcome: half-applied security policy is worse
than none.
