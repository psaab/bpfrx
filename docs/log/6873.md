# #6873 — host-inbound unknown-zone admit: cold-boot reachability

- **Timestamp**: 2026-08-27
- **Action**: Establish whether the cold-boot window is reachable, and pin the
  invariant that answers it
  - **The premise is half right, and the fix direction inverts.** The gap is
    real: `host_inbound_admits` has no `snapshot_installed` consultation, and
    an empty `zone_host_inbound` sends EVERY zone id to `None => true`. But the
    empty table is not observable, so a gate at the admit site would be dead
    code — a check on a state no reader can reach.
  - **Measured, by tracing the worker lifecycle rather than the flag**:
    - `bring_up_workers` is the only worker spawn path (README:133 forbids a
      bare `std::thread::spawn` for a worker); reconcile runs `tear_down` ->
      `apply_snapshot` -> `bring_up_workers`, so a worker is spawned only after
      a snapshot-derived state is published.
    - `reconcile(None, ..)` takes its early exit AFTER `tear_down`, so "no
      snapshot" means "no workers", never "workers on an empty table".
    - `stop_inner` JOINS every worker via `workers.stop_and_clear(..)` BEFORE
      `self.forwarding = ForwardingState::default()` (#6592). The reset is never
      visible to a live reader; the code says so itself.
  - **The invariant was load-bearing and unpinned.** The closest existing cell,
    `reconcile_with_none_snapshot_reaches_no_snapshot_early_exit` (#1328),
    asserts `workers.live.is_empty()` from a `Coordinator::new()` that never had
    a worker — remove the teardown and it stays green. A fixture that cannot
    produce the state it asserts absent is mutation-insensitive by construction,
    and that one has read like coverage since #1328.
  - **Two cells, in this order, because the second asserts an ABSENCE**:
    1. `cold_forwarding_state_admits_every_host_inbound_service_6873` — the
       PAYLOAD PROOF. A default `ForwardingState` admits ssh, https, v6 DNS and
       raw GRE through `host_inbound_admits_iface`, the entry point the
       local-delivery poll path calls. Carries a control: the same packets on
       the same zone id are DENIED once the zone is in the table, so the cell
       shows EMPTINESS is the cause rather than the admit path being open.
       None of the four probes is ICMP, so none can reach admit via the
       #3171/#3201 global accept.
    2. `no_snapshot_reconcile_leaves_no_reader_for_the_empty_table_6873` — the
       ORDERING GUARD, built from a coordinator that HAS a live worker record
       AND a populated host-inbound table. Asserts the dangerous state is
       reached (table emptied) AND that nothing survives to observe it.
  - **The comment rewrite is the anti-re-close deliverable.** The `None => true`
    arm cited #3405 and #5659 — both accurate, neither answering the question —
    and so read as settled. It now states which cases are settled and by which
    issue, what stays admitted ON PURPOSE, and the ordering argument with its
    citation.
