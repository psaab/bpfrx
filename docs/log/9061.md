# 9061 — a peer IPsec SA frame with no element or name bound

- **Timestamp**: 2026-09-06
- **Action**: bound the peer-supplied IPsec SA full set, stop the decoded names
  aliasing the frame, and refuse a malformed set rather than installing it.
- **File(s)**: `pkg/cluster/sync_protocol.go`, `pkg/cluster/sync_conn_read.go`,
  `pkg/cluster/ipsec_sa_payload_bound_9061_test.go` (new), plus two existing
  call sites for the new two-value signature.

## Measured before, at the 16 MiB frame ceiling

```
16 MiB of "\n"    -> 16,777,217 parts, 272.1 MB transient, 0 names retained
16 MiB of "a\n"   ->  8,388,609 parts, 674.8 MB transient, 128 MB RETAINED
```

**The retained set is the sharper end, twice over.** Every one-byte name from
`strings.Split` is a substring sharing the payload's backing array, so the whole
16 MiB stays reachable while any name does. And `reinitiateIPsecSAs` iterates the
retained set **on takeover**, calling `InitiateConnection` per name — 8.4 M
exec-shaped calls on the failover path, so the cost lands exactly when the
cluster is least able to absorb it.

## Three parts, and each needed its own mutant

1. **Bounds** — `maxIPsecSANames` (4096) and `maxIPsecSANameLen` (256). The
   second is not redundant: without it a single enormous "name" stands in for the
   element bound.
2. **Copy, don't alias** — the decoder scans the payload and converts each name
   individually, so retained size is proportional to the *names* rather than the
   frame.
3. **Refuse, don't truncate** — the arm beside this one already states the
   doctrine for its own full set: *"a full set REPLACES, so installing a stale or
   truncated one is worse than installing nothing."* A truncated SA set makes the
   standby reinitiate a **subset** on takeover and look like it succeeded.

## Two gaps the mutation pass found, not the reading

**The receiver wiring was unbound.** Three cells tested the decoder; a mutation
making `handleMessage` install a malformed set anyway **killed zero of them** —
the defect restated one layer up, since a bound only matters if the caller acts
on it. `TestMalformedIPsecSAFrameDoesNotReplaceTheHeldSet9061` drives
`handleMessage` and asserts the held set is unchanged; it kills that mutant.

**My first aliasing mutant was not one.** `string(b)` inside a helper still
copies, so it survived and proved nothing. The honest mutant is the *actual*
original — `strings.Split(string(payload), "\n")` — which aliases, and which the
aliasing cell kills. Recorded because a mutant that cannot express the defect is
a mutant that reports coverage it did not test.
