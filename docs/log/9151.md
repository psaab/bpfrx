# #9151 — the schema said LEAF where the compiler reads a CONTAINER

- **Timestamp**: 2026-09-06
  - **Action**: declared `protocols rip group`'s children to match what the
    compiler reads. **This does NOT close #9151**, and the gap is pinned as a
    live assertion rather than left in prose.

    ```
    schema     protocols rip group   args=1 children=nil   -> a LEAF
    compiler   case "group": for _, gc := range child.Children
                 case "neighbor": -> RIP.Interfaces
                 case "export":   -> RIP.Redistribute
    ```

    Both are read through `firewallMatchValues` (Keys[1:] AND child nodes,
    #3904), so both are declared `multi` — otherwise a bracket list
    `export [ a b ]` truncates to its first entry.

    **What the declaration buys, measured:**

    ```
    group g1 neighbor ge-0/0/0        ACCEPT  ifaces=[ge-0/0/0]
    group g1 export static            ACCEPT  redist=[static]
    group g1 + split authentication   ACCEPT  ifaces=[ge-0/0/0] authKey="secret1"
    ```

    **What it does NOT buy, also measured:**

    ```
    group g1 authentication-key secret1   ACCEPT  ifaces=[] redist=[] authKey=""
    ```

    Still commits clean, still loses both. Declaring the children makes the
    schema HONEST about what the compiler reads; it does not refuse an
    UNDECLARED trailing statement, because `protocols rip` is open-world. By
    the #9148 conjunction a flat run is accepted iff the container is
    open-world AND the starting leaf is untyped — and this declaration changes
    neither.

    **The gap is a cell, not a comment.**
    `TestRipGroupPackedRunStillAdmitted9151` asserts the packed run is still
    admitted and **skips with an instruction to delete itself** the moment the
    schema gate starts refusing it. A landed partial fix removes the reason
    anyone looks again, which is the failure #8942 catalogued; a cell that
    fails when the real fix arrives cannot rot into a false all-clear.

    Closing it needs an admission change — flipping the container closed-world,
    or teaching the compiler to walk the run — and that is a user-visible
    decision I am not taking unilaterally, the same call I have been requiring
    of the lanes.
