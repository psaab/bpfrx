## The decline is the finding

`system services` measures like a textbook admission. Every column this issue
adjudicates on says admit: gate SILENT, zero warnings, both spellings accepted
at strict commit, braced arm live against an empty config, elided arm dropping
the whole stanza, not inert.

It was admitted, and the **full package suite** went red on
`TestPackedLoginBehindAnotherSystemStatementIsRejected_6966`.

With `system services` folded, `system services ssh login user alice class ops;`
parses into the services container; `login` is not a child of `ssh`, so the
stanza is dropped — but strict commit now **ACCEPTS** it. That is #6966
re-opened: the CLI then runs with an empty class. Admitting the pair trades a
loud rejection for a silent acceptance, which is the #8868 shape exactly.

**No measurement of the pair itself could have caught this.** The damage is to a
*different statement* that happens to pack behind it. A pair's own before/after
columns cannot see a regression in a sibling statement — only the whole suite
can. That is the argument for gating these batches on the full package rather
than on the cells they add, and it is now the second time a scoped gate would
have shipped a defect in this campaign.

Recorded as `TestSystemServicesStaysUnadmitted8879`, asserting both the flag and
the property behind it.

## The second finding: an elision that disarmed its own detector

`routing-options forwarding-table export <policy>` is validated at strict commit
— naming an undefined policy-statement is refused, with an error that says the
consequence out loud ("the expected ECMP / consistent-hash load-balancing would
be silently disabled").

Before this admission the elided spelling dropped the export leaf **before that
check ran**:

    braced, undefined policy  ->  REJECTED at commit   (correct)
    elided, undefined policy  ->  COMMITTED CLEAN      (fail-open)

The operator got no value AND no complaint. This is the worst of the three
shapes #8879 has turned up — a silent drop that also disarms its own detector —
and it inverts the usual intuition that the more explicit spelling is the risky
one. Measured two-sided: removing the admission restores the fail-open.

Pinned by `TestElisionSuppressedAValidation8879`, whose liveness assertion is
fatal on purpose: if the braced arm ever stops being refused, the check no
longer exists and the cell would pass for the wrong reason.

Note the fixture split this forced. The admission row for the same pair uses a
**defined** policy, because with an undefined one the braced arm is rejected and
the row would measure the dangling-reference check instead of the drop. Two
questions, two fixtures.
