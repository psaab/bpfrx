# #9006 — the census diagnostic pointed at master for an untracked local file

- **Timestamp**: 2026-09-05
  - **Action**: split the UNTRACKED case out of the census's undeclared-harness
    failure, because the two need opposite remedies and the generic text sent
    the untracked case to the wrong one — including one remedy that trips a
    different check.

    Found by running `make selftest` and getting `155 passed / 2 failed` where
    another lane had measured 157/0 on a fresh checkout. The offender was
    `test/incus/per-stream-diag.sh`, **untracked** — a scratch file in my own
    working tree. The census scans the filesystem, which is correct; the
    message is what misdirects:

    > UNREACHED and undeclared -- invoked by no Makefile recipe …
    >   - add a Makefile recipe that runs it, or
    >   - add a line to HARNESSES.unreached

    Neither applies to a local scratch script, and the second is **actively
    wrong**: `HARNESSES.unreached` may only name committed paths, and a
    declaration for a path not in the tree is itself a FAIL. Following the
    printed remedy produces a second, different failure. I spent a cycle
    looking through recent commits for a harness someone had added before
    checking `git ls-files`.

    **Hermeticity was the design constraint, not an afterthought.** This
    script's contract is "a pure file scan … it either scans the tree or fails
    to start", and a hard `git` dependency is exactly what broke it once
    before, when a `mktemp` added to the census died in the restricted-PATH
    leg. Git is used ONLY to refine the remedy text — never the verdict, never
    the exit status, never whether the scan runs. With no git, or outside a
    repo, every path falls through to the original message and the census
    behaves bit-identically. Verified by running it outside a git repo: no
    UNTRACKED text, generic message, census still scans.

    **Two cells, because one direction does not bound it.** The untracked case
    must produce the UNTRACKED text and NOT the generic one; the tracked case
    must produce the generic text and NOT the UNTRACKED one. A branch firing
    for both would pass either cell alone. Git-gated so the suite SKIPs them
    rather than depending on git.

    Mutation, each killed by its own cell: collapsing the branch reds the
    untracked cell; inverting it reds the tracked cell.
