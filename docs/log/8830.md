## Why the shipped remedy could not close it

#8807's converse predicate asks whether any `.Name()` clause at the container
names the head — a question about the SOURCE. The landed remedy adjudicates each
reported hit, which is a PRECISION discipline: it iterates `hits`, so a head the
predicate never reported is never adjudicated. #8830 is a RECALL defect, and the
two are orthogonal.

## What the new cell does

Compiles a fixture with and without the statement and compares the whole
`*Config`, `Warnings` included. If adding the statement changes nothing, the
value reaches nothing — whatever the source looks like.

## Measured

The false negative demonstrated on a REAL head, both directions, one experiment.
Dropping the value in `case "dh-group"` while leaving the clause in place:

    AST predicate converseHits8807   reports dh-group : false   (blind)
    behavioural cell                 FAILS: "the value reaches nothing"

And the issue's own acceptance mutation — adding `case "description": _ = v` to
the IKE proposal compiler — makes the AST predicate go quiet while this cell
still reports UNREAD.

`policy / description` moved from NOT MEASURED in `converseAdjudicated8807` to
measured, and it is genuinely unread.

## Limits, stated

Coverage is the containers given fixtures, not a census: 13 rows across three
containers. Within them no LIVE false negative exists — every head carrying a
clause is behaviourally read — so the class is proven by mutation rather than
observed in production code. Widening means adding fixtures, and the liveness
check is FATAL rather than skipped because a fixture compiling to an empty
config would score every row UNREAD.
