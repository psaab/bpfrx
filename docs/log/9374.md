## Measured at this head

```
routing-instances { V { instance-type vrf; protocols {
    router-advertisement { interface ge-0/0/0.0 { max-advertisement-interval 30; } } } } }
  -> STRICT COMMIT ACCEPTS      cfg.Warnings = 0
  -> ri.OSPF/OSPFv3/BGP/RIP/ISIS all nil
  -> cfg.Protocols.RouterAdvertisement empty

routing-instances { V { instance-type vrf; protocols { lldp { interface ge-0/0/0.0; } } } }
  -> same: accepted, compiled to nothing, silent
```

`compileRoutingInstances`' `case "protocols"` calls the shared
`compileProtocols` and copies five fields out of the result. Everything else
goes out of scope with the local value.

**This one is OPERATOR-REACHABLE** — `strictOK=true` — which is what separates
it from the 25 lenient-only rows of #9391. Per-instance
`router-advertisement` is a real Junos spelling, so an operator can reasonably
write it, `show configuration` renders it back, and the box does not send RAs
on that instance's interfaces.

## Remedy: a warning, and a derived one

A new commit rejection has repo-wide blast radius and would refuse a config
that boots and forwards today. #1960's doctrine is to keep it working and say
so, so this warns through `cfg.Warnings` (the `show system commit warnings`
channel).

**The set is derived, not listed.** It is every child of the per-instance
`protocols` node that `schemaRoutingInstanceProtocols` does not declare, and
that node's membership is bound to the compiler's copy set by
`TestRoutingInstanceProtocolsShareTheGlobalGrammar9351`, which reads the
`ri.X = proto.X` assignments out of the SOURCE.

So the chain is **compiler copy set → schema membership → this warning**, with
no list anywhere that can fall out of date. Wiring a copy silences the warning;
adding a protocol the compiler discards raises it.

A broken schema lookup returns NO warnings rather than warning about
everything — a lookup failure must not become a screen of warnings on every
routing instance.

## Cells

`TestInertProtocolWarningIsDerivedNotListed9374` sweeps every child of the
global `protocols` grammar and requires **warn IFF not-carried**, with a
vacuity guard on both sides: 7 keywords, 5 carried, 2 warned. Three negative
arms stop the whole thing being "warn about everything" — a carried protocol,
the global spelling, and an `apply-*` meta keyword must all stay silent.
