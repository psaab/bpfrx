  - **A flaw in my own tooling, found here.** My mutation harnesses counted
    "collected" with `awk -F'[ ;]' '{p+=$4; f+=$6}'`. On a `test result:` line
    the failed count is field **7**, not 6 — `$6` is the empty field created by
    `"; "`. So "collected" has been reporting **passed-only** all along. In
    control runs (0 failed) that is identical, which is why it never showed; in
    a mutation cell it under-reports by exactly the failure count. The
    reporting-BINARY count, which is the check that actually distinguishes a
    build break, was unaffected. Corrected to sum `[0-9]+ (passed|failed)`.
