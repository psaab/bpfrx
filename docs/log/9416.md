## Two findings this change did not set out to make

**The #5833 quarantine was armed and unreachable.** `AllowsSource` returned
allow-all on `len(Clients) == 0` BEFORE consulting `clientNets`, and #5833
deliberately writes the quarantine only into `clientNets`. That worked because
a malformed INLINE token still leaves the token in `Clients`. An unresolvable
`client-list-name` leaves no residue, so the community carried an explicit
deny-all match set and served every source. The predicate is now
`len(Clients) == 0 && clientNets == nil`.

**The reconcile hash could not see it either.** A community whose only
restriction is an unresolvable reference has an empty `Clients`, so adding such
a reference to a previously-unrestricted community hashed EQUAL and the running
agent kept serving every source — the #5105 class through a new door. The
authored references are now hashed.
